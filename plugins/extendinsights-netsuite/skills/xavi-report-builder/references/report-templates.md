# Report index

Read _conventions.md and rules.md, then the applicable report file. Load Office.js
notes before using that API and README guidance before documenting the result.

| Request | File |
|---|---|
| Summary P&L / CFO Flash / year-over-year / detailed income statement | [Income statements](templates-income-statement.md) |
| Balance Sheet / Trial Balance | [Balance and trial balances](templates-balance-sheet.md) |
| Budget vs. Actual | [Budget comparisons](templates-budget.md) |
| Cash flow statement | [Cash flow draft](templates-cashflow.md) |
| Subsidiary comparison / executive dashboard | [Dashboard and subsidiary comparison](templates-dashboard.md) |

For a custom report, identify its period, account scope, filters and reconciliation
before adapting a template. A report requiring unavailable source data remains a
draft; do not manufacture accounts, financial values or verification.
